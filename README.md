## 🚀 Featured Projects

### ✨ Constellate

**AI Atlas for Rare Diseases · Hack-Nation 2026**

An evidence-graded knowledge graph that connects rare diseases through genes, phenotypes and mechanisms rather than disease names alone.

Built as part of a team during the **Hack-Nation 7th Global AI Hackathon – Vienna Hub**.

[**View Project →**](https://github.com/hannokuegler/constellate)

`Next.js` `Python` `OpenAI` `Knowledge Graphs` `Data Pipelines`

---

### 🤟 Signly

**Browser-based Sign Language Recognition**

A hackathon prototype for recognizing isolated ASL signs directly in the browser using hand and upper-body landmarks with local inference.

Recognition runs on-device without requiring cloud inference.

[**View Project →**](https://github.com/Reczec/signly)

`TypeScript` `React` `MediaPipe` `ONNX Runtime` `Machine Learning`

---

### 🤖 Job Pilot Automation

**AI-assisted job application command center**

A local automation system that gathers jobs, filters them by location and experience level and prepares application material while keeping the final submission under user control.
